Etiquetas HTML Esenciales

Desde HTML4 hasta HTML5: estructura, símbolos y elementos clave

¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Define la estructura del contenido mediante etiquetas rodeadas por los símbolos < y >.

HTML4 vs HTML5

HTML4 (1997) introdujo mejoras en accesibilidad y separación de contenido/estilo. HTML5 (2014) añadió nuevas etiquetas semánticas (<header>, <section>, etc.), soporte nativo para audio/video, y APIs modernas.

¿Por qué los símbolos < y >?

Estos símbolos indican el inicio y fin de una etiqueta. Por ejemplo: <p> inicia un párrafo y </p> lo cierra. El navegador los interpreta como instrucciones, no como texto visible.

<!DOCTYPE html>

Declara que el documento usa HTML5. Debe ir al inicio del archivo. 

<!DOCTYPE html>
<html lang="es">
  ...
</html>

<html>

Es la raíz de todo documento HTML. Contiene todo el contenido de la página. 

<html lang="es">
  <head>...</head>
  <body>...</body>
</html>

<head>

Contiene metadatos: título, enlaces a CSS, scripts, codificación, etc. No se muestra en la página.

<title>

Define el título de la página (aparece en la pestaña del navegador). 

<head>
  <title>Mi Página Web</title>
</head>

<body>

Contiene todo el contenido visible de la página: texto, imágenes, enlaces, etc.

<link>

Enlaza recursos externos, como hojas de estilo CSS. Es una etiqueta autocerrante. 

<link rel="stylesheet" href="estilo.css">

<p>

Define un párrafo de texto. 

<p>Este es un párrafo.</p>

<h1> a <h6>

Encabezados de diferentes niveles. <h1> es el más importante, <h6> el menos. 

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Sección menor</h3>

<header>

Representa la cabecera de una página o sección (introducido en HTML5). Suele contener logotipos, menús o títulos. 

<header>
  <h1>Mi Sitio Web</h1>
  <nav>...</nav>
</header>

<div>

Contenedor genérico sin significado semántico. Se usa para agrupar elementos y aplicar estilos. 

<div class="contenedor">
  <p>Contenido dentro de un div</p>
</div>

<section>

Representa una sección temática del contenido (HTML5). Tiene significado semántico, a diferencia de <div>. 

<section>
  <h2>Noticias</h2>
  <p>Últimas actualizaciones...</p>
</section>

<footer>

Pie de página de un documento o sección. Puede contener información de contacto, enlaces legales, etc. 

<footer>
  <p>© 2026 Mi Empresa</p>
</footer>
