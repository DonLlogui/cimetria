Conceptos Fundamentales de la Web

Explicaciones claras y detalladas para entender cómo funciona internet

¿Qué es una IP?

Una IP (Internet Protocol) es una dirección numérica única que identifica a un dispositivo en una red. Por ejemplo, 192.168.1.1 o 2001:db8::1 (IPv6). Es como la "dirección postal" de una computadora o servidor en internet, permitiendo que los datos se envíen y reciban correctamente.

¿Qué es un Puerto?

Un puerto es un número asociado a una conexión de red que permite distinguir entre diferentes servicios o aplicaciones en un mismo dispositivo. Por ejemplo, el puerto 80 se usa para HTTP y el 443 para HTTPS. Piensa en él como el "número de apartamento" en una misma dirección IP.

¿Qué es una URL?

Una URL (Uniform Resource Locator) es la dirección completa que usas para acceder a un recurso en internet. Ejemplo: https://www.ejemplo.com/pagina.html. Incluye el protocolo (https), el dominio (ejemplo.com), y a veces la ruta al recurso específico.

¿Qué es un Dominio?

Un dominio es un nombre fácil de recordar que representa una dirección IP. Por ejemplo, en lugar de escribir 142.250.185.206, puedes escribir google.com. Los dominios se gestionan mediante servidores DNS que traducen nombres a direcciones IP.

¿Qué es Hosting?

El hosting (o alojamiento web) es el servicio que almacena los archivos de tu sitio web en un servidor conectado a internet. Sin hosting, tu sitio no estaría accesible para otros usuarios. Existen distintos tipos: compartido, VPS, dedicado, en la nube, etc.

Programación del Lado del Cliente

Se refiere al código que se ejecuta en el navegador del usuario. Incluye tecnologías como HTML, CSS y JavaScript. Su función principal es manejar la interfaz de usuario, validar formularios y hacer la web interactiva sin necesidad de comunicarse constantemente con el servidor.

Programación del Lado del Servidor

Es el código que se ejecuta en un servidor remoto antes de enviar la página al navegador. Usa lenguajes como PHP, Python, Node.js, Ruby o Java. Maneja bases de datos, autenticación, lógica de negocio y genera contenido dinámico para enviarlo al cliente.

Petición y Respuesta (Request/Response)

Este es el modelo fundamental de comunicación en la web. Cuando visitas una página, tu navegador hace una petición (request) al servidor. El servidor procesa esa petición y devuelve una respuesta (response) (por ejemplo, una página HTML). Este ciclo ocurre cada vez que cargas una página, envías un formulario o consumes una API.
